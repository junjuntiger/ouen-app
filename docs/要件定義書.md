# 要件定義書

**プロジェクト名：** shinEDO-ouen（OUEN-APP）
**作成日：** 2026-06-25
**更新日：** 2026-08-17
**バージョン：** 2.0（Supabase移行版）

---

## 1. 目的・背景

日本の伝統工芸・伝統芸能・地域文化を担う職人や演者は、
活動の継続に経済的困難を抱えるケースが多い。
一方、応援したいと考える人々は「どう支援すべきか分からない」という課題がある。

本アプリは、**現金での支払いに感謝の上乗せ（応援）を加える**という
シンプルな仕組みで、支援の文化を可視化・促進することを目的とする。

---

## 2. 対象ユーザー

### 受け取る側（伝統文化の担い手）
- 伝統工芸の職人・作家
- 伝統芸能の演者・師匠
- 地域文化の活動家・保存団体

### 支払う側（応援者）
- 日本文化を愛好する一般市民
- 伝統文化のファン・コレクター
- 地域コミュニティのメンバー

## 3. 機能要件

| AUTH-01 | メールアドレス＋パスワードでの新規登録・ログイン | 必須 | 実装済み |
| AUTH-02 | メールアドレス確認（Supabaseの設定に応じて有効/無効） | 必須 | 実装済み |
| AUTH-03 | ログアウト | 必須 | 実装済み |
| AUTH-04 | ログイン状態の永続化 | 必須 | 実装済み（Supabaseセッション） |

### 3-2. プロフィール機能

|---|---|---|---|
| PROF-01 | 初回ログイン時のプロフィール登録 | 必須 | 実装済み |
| PROF-02 | 名前・職業・地域・ひとことの編集 | 必須 | 実装済み |
| PROF-03 | 定価メニューの登録・編集・削除 | 必須 | 実装済み |
| PROF-04 | プロフィール写真のアップロード | 必須 | 実装済み（Supabase Storage） |

### 3-3. おーえん（取引）機能
| ID | 機能 | 優先度 | 状態 |
|---|---|---|---|
| OUEN-01 | メンバー検索（名前・職業・地域）での相手特定 | 必須 | 実装済み |
| OUEN-02 | 定価メニューの複数選択・数量指定 | 必須 | 実装済み |
| OUEN-03 | 選択項目ごとの支払い金額入力 | 必須 | 実装済み |
| OUEN-04 | 「その他」項目の自由入力追加 | 必須 | 実装済み |

|---|---|---|---|

---

## 4. 非機能要件

| 項目 | 要件 |
|---|---|
| レスポンシブ | モバイル最適化のUIだが、画面幅は固定せずブラウザ幅いっぱいに表示 |
| パフォーマンス | 初回ロード数秒以内（Vercel配信の静的SPA） |
| セキュリティ | Supabase Row Level Security（RLS）で認証・アクセス制御必須 |
| 可用性 | Supabase・Vercel のSLA準拠 |
| データ整合性 | Postgres関数（SECURITY DEFINER）による原子的なOP加算 |

---

## 5. 制約・除外事項

- OP は記録専用。購入・換金・移転はできない
- 実際の金銭決済機能は持たない（現金取引の記録のみ）
- マイナスOPは発生しない（支払い ≥ 定価のみ記録）
- 取引に承認フローはなく、送信と同時に相手のOPへ即時反映される
- QRコードによる相手特定は未実装（名前・職業・地域での検索のみ対応）
- プロフィール写真の内容モデレーション（不適切画像の自動検知）は未実装
