## 手順1：リポジトリのクローン

```bash
git clone https://github.com/YOUR_USERNAME/OUEN-APP.git
cd OUEN-APP
```

---

## 手順2：依存パッケージのインストール

```bash
npm install
```

インストールされる主なパッケージ：

| パッケージ | 用途 |
|---|---|
| react, react-dom | UIフレームワーク |
| react-router-dom | ページ遷移 |
| @supabase/supabase-js | 認証・DB・Storageクライアント |
| vite | ビルドツール |

---

## 手順3：環境変数の設定

プロジェクトルートに `.env` を作成する。

```bash
cp .env.example .env
```

`.env` を開き、以下の値を設定する：

```
VITE_SUPABASE_URL=https://xxxxxxxx.supabase.co
VITE_SUPABASE_ANON_KEY=sb_publishable_xxxxxxxxxxxxxxxxxxxx
```

> Supabaseの値は Supabase Dashboard → Project Settings → API から確認できる（`anon`／`publishable`キーを使用し、`service_role`キーはフロントエンドに置かないこと）。

---

## 手順4：Supabase の設定

### 4-1. Authentication の確認

1. [Supabase Dashboard](https://supabase.com/dashboard) を開く
2. 対象プロジェクトを選択
3. 左メニュー → **Authentication** → **Sign In / Providers** → **Email** が有効になっていることを確認
4. **Authentication → Emails** で確認メール（Confirm signup）の要否を確認。既定ではメール確認が必須

### 4-2. データベーススキーマの適用

1. 左メニュー → **SQL Editor** → **New query**
2. `supabase/schema.sql` の内容を貼り付けて **Run**（テーブル・RLS・RPC関数・Storageバケットを作成）
3. 続けて `supabase/migration_002_avatar.sql` の内容を貼り付けて **Run**（プロフィール写真機能に必要な列とStorage設定を追加）
4. 左メニュー → **Table Editor** で `profiles` / `transactions` テーブルが作成されていることを確認

---

## 手順5：開発サーバーの起動

```bash
npm run dev
```

ブラウザで http://localhost:5173 を開く。

---

## 手順6：Vercel へのデプロイ

### 6-1. Vercel にプロジェクトを登録

1. [Vercel](https://vercel.com/) にログイン
2. **New Project** → GitHubリポジトリ `OUEN-APP` を選択
3. **Framework Preset**：Vite を選択

### 6-2. 環境変数を Vercel に設定

Vercel プロジェクト設定 → **Environment Variables** で
`.env` の内容（`VITE_SUPABASE_URL` / `VITE_SUPABASE_ANON_KEY`）をすべて登録する。

### 6-3. デプロイ実行

```bash
git add .
git commit -m "初回コミット"
git push origin main
```

GitHub への push で Vercel が自動的にデプロイを開始する。

## よくある問題と対処法

### 新規登録で「email rate limit exceeded」

**原因：** Supabase組み込みメール送信（無料枠の標準SMTP）のレート制限に達した

**対処：**
1. 1時間程度待って再試行する
2. または Supabase Dashboard → Authentication → Users → **Add user** → **Create new user** で、「Auto confirm user」をONにして直接ユーザーを作成する（確認メール不要）
3. 本番運用では Authentication → Emails からカスタムSMTP（Resendなど）を設定することを推奨

---

### `Cannot find module '@supabase/supabase-js'` エラー

**原因：** npm install が完了していない

**対処：** node_modules フォルダを削除してから `npm install` を再実行する

---

### プロフィール取得・更新でエラーになる（RLS関連）

**原因：** `supabase/schema.sql` が未適用、またはログインユーザーとRLSポリシーの条件が一致していない

**対処：**
1. Supabase Dashboard → Table Editor で `profiles` / `transactions` テーブルの存在を確認
2. 手順4-2のSQLが正しく実行されているか確認
3. Authentication → Policies で対象テーブルのRLSポリシーが表示されているか確認

---

### おーえん送信時に失敗する

**原因：** `create_ouen_transaction` RPC関数が未作成

**対処：** `supabase/schema.sql` を再確認し、RPC関数（`create_ouen_transaction`・`is_admin`）が作成されているかSQL Editorの `select * from pg_proc where proname = 'create_ouen_transaction';` などで確認する

---

### Vercel デプロイ後に白画面

**原因：** 環境変数が設定されていない

**対処：**
1. Vercel → プロジェクト → Settings → Environment Variables
2. `VITE_SUPABASE_URL` / `VITE_SUPABASE_ANON_KEY` が設定されているか確認
3. 再デプロイ：Vercel → Deployments → Redeploy
