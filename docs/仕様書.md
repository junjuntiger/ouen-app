## 3. 各画面の仕様

### SCR-01 ログイン／新規登録画面

**目的：** メールアドレス＋パスワードでユーザーを識別する

**表示要素：**
- shinEDO-ouenロゴ
- 「ログイン」／「新規登録」タブ
- メールアドレス入力欄
- パスワード入力欄
- 送信ボタン（ログイン時／登録時で文言切替）

**挙動：**
- ログイン：`supabase.auth.signInWithPassword`
- 新規登録：`supabase.auth.signUp`。Supabase側でメール確認が有効な場合はセッションが即発行されず、「確認メールを送信しました」という案内を表示してログインタブに戻す
- ログイン成功後は自動的に `/` または `/profile-setup` へ遷移（プロフィール有無で分岐）

**エラー表示（日本語化）：**
- メールアドレス／パスワード不一致：「メールアドレスまたはパスワードが正しくありません」
- 登録済みメール：「このメールアドレスは既に登録されています」
- パスワードが短い：「パスワードは6文字以上で入力してください」
- メールアドレス形式不正：「正しいメールアドレスを入力してください」

---

### SCR-02 プロフィール設定画面

**目的：** 初回ログイン時にプロフィールを作成する

**表示要素：**
- お名前（必須）
- 職業・活動
- 地域
- ひとこと
- 定価メニュー（複数追加可・名前と金額のペア）
- 「プロフィールを登録する」ボタン

**挙動：** `profiles`テーブルにレコードをinsert（`id`=Auth uid、`op`初期値0）。完了後SCR-03へ遷移

---

### SCR-03 ホーム画面

**目的：** OP残高の確認と最新おーえん情報の閲覧

**表示要素：**
- shinEDO-ouenロゴ
- OP残高カード（自分の現在OP）
- 最近のおーえんタイムライン（直近20件、全ユーザー分・取得時にJOINで送信者/受信者名を解決）
  - 送信者名 → 受信者名、メニュー内容、支払額、獲得OP、日時

**データ取得：** `transactions`テーブルを`created_at`降順で取得（1回読み込み、リアルタイム購読なし）

---

### SCR-04 おーえんする画面（3ステップ）

**目的：** 相手を選んで応援（取引）を記録する

```
Step1: メンバー選択
  - 自分以外の全メンバーを名前・職業・地域で検索
        │
        ▼
Step2: メニュー・金額
  - 相手の定価メニューから複数選択（数量増減可）
  - 選択した行ごとに支払い金額を入力（定価以上）
  - 「その他」で自由記述の項目も追加可能
  - メッセージ（任意）
        │
        ▼
Step3: 確認
  - 内容サマリー（各項目の定価→支払額、定価合計、支払合計、獲得OP）を表示
  - 「おーえんする！」→ 送信
```

**送信処理：** Supabase RPC `create_ouen_transaction()` を1回呼び出し、取引レコードのinsertと相手のOP加算をデータベース側でアトミックに実行する（クライアントから相手のレコードを直接更新することはない）

**バリデーション：**
- 支払い金額 ≥ 定価合計
- 自分自身は候補一覧から除外（送信不可）

**完了画面：** 獲得OPを表示し、「続けておーえんする」で最初のステップに戻れる

---

### SCR-05 メンバー一覧画面

**目的：** 登録メンバーを一覧・ランキングで確認する

**表示要素：**
- 検索バー（名前・職業・地域・ひとことで絞り込み）
- OPランキング（上位3名、検索していない時のみ表示）
  - 1位「松」／2位「竹」／3位「梅」のバッジ
- 全メンバーリスト（OP降順）
  - プロフィール写真（未設定時はイニシャル丸アイコン）
  - 名前・職業・地域・ひとこと
  - 自分の行には「あなた」バッジ
  - OP残高、「おーえん」ボタン（他人の行のみ）

---

### SCR-06 マイページ画面

**目的：** 自分の情報確認・編集

**表示要素：**
- ヘッダー：プロフィール写真、名前、職業／地域、OP残高
- タブ：「取引履歴」／「プロフィール編集」

**取引履歴タブ：**
- 支払い・受取フィルタ、期間フィルタ（今月／先月／先々月／その前／全て）
- 各取引：メニュー名、相手名、日付、メッセージ（あれば）、支払額、OP

**プロフィール編集タブ：**
- 「写真を変更」ボタン → 画像選択（5MB以内、画像ファイルのみ）→ Supabase Storageへアップロード
- 名前・職業・地域・ひとこと・定価メニューの編集
- `is_admin`が`true`の場合のみ「管理画面へ」ボタンを表示
- ログアウトボタン

---

### SCR-07 管理画面（is_admin限定）

**目的：** 全体統計の確認、ユーザー・取引の管理

**アクセス制御：** `userProfile.is_admin`が`false`の場合はホームへリダイレクト

**表示要素（タブ切替）：**
- 統計：総ユーザー数、総取引件数、総売上、総発行OP
- ユーザー：一覧表示、OP残高をクリックして手動編集可能
- 取引履歴：一覧表示、各行に削除ボタン（確認ダイアログあり）

## 5. データモデル概要

### `profiles`
| カラム | 型 | 備考 |
|---|---|---|
| id | uuid (PK) | `auth.users.id`を参照 |
| name | text | 必須 |
| job / area / message | text | 任意 |
| op | integer | 初期値0 |
| menus | jsonb | `[{name, price}]` |
| avatar_url | text | プロフィール写真の公開URL |
| is_admin | boolean | 手動でのみ`true`に変更（管理者権限） |
| created_at | timestamptz | |

### `transactions`
| カラム | 型 | 備考 |
|---|---|---|
| id | uuid (PK) | |
| from_user_id / to_user_id | uuid | `profiles.id`を参照 |
| menu_name | text | 選択メニューのサマリー文字列 |
| items | jsonb | 明細（`name, price, quantity, paid`） |
| price / paid / op | integer | 定価合計／支払合計／獲得OP |
| message | text | 任意 |
| created_at | timestamptz | |

### RPC関数
- `create_ouen_transaction()`：取引作成とOP加算をアトミックに実行（SECURITY DEFINER）
- `is_admin()`：RLSポリシー内で管理者判定に使用するヘルパー

---

## 6. 認可・セキュリティ概要

- 全テーブルでRow Level Security（RLS）を有効化
- `profiles`：全ユーザーが閲覧可能（メンバー一覧・タイムライン表示のため）、書き込みは本人または管理者のみ
- `transactions`：全ユーザーが閲覧可能、直接INSERTは不可（`create_ouen_transaction()`経由のみ）、削除は管理者のみ
- Storage（`avatars`）：読み取りは公開、書き込みは本人の`{uid}/`フォルダのみ許可

詳細は`supabase/schema.sql`および`supabase/migration_002_avatar.sql`を参照。
